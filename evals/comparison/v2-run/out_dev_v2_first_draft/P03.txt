Rate limiting

Each API key is limited to 100 requests per minute, which keeps usage fair and performance steady for everyone. If you go over, the API returns a `429 Too Many Requests` response with a `Retry-After` header giving the number of seconds to wait before retrying.

We recommend exponential backoff in your client. Wait 1 second after the first failed attempt, double the wait after each one that follows, and stop doubling at 32 seconds. Cache responses wherever you can, too. It cuts the number of requests you make and makes your application respond faster.
