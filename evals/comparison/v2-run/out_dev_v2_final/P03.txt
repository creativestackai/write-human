Rate Limiting

Our API rate-limits requests to keep usage fair and performance steady for all users. Each API key is limited to 100 requests per minute. Go over that and the API returns a `429 Too Many Requests` response with a `Retry-After` header giving the number of seconds to wait before you retry.

We strongly recommend implementing exponential backoff in your client to handle rate limits. Start with a delay of 1 second and double it after each failed attempt, up to a maximum of 32 seconds. Also cache responses wherever you can. It cuts the number of requests and makes your application more responsive.
