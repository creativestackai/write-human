Motivation comes and goes, so it's a poor thing to build on. Habits hold up better. Do something small every day for a few months and it adds up to more than it seems like it should.

Willpower runs out too, so set things up so the good behavior happens without you having to decide each time. Start with something small enough that you can't really skip it, write down what you do, and give yourself some slack when you miss a day. If you haven't started yet, start today.
